# Contributing

Contributions that keep this list useful and current are welcome.

## What belongs here

A proposed entry should be directly relevant to quantitative research on face perception and should provide at least one of the following:

- an open-source software implementation;
- a publicly accessible model, standard, database, or reference resource;
- a tool for face reconstruction, measurement, transformation, model fitting, model selection, or model interpretation.

The resource should have a stable public page or repository. Commercial tools without a public research resource are generally outside the scope of the list.

## How to contribute

The easiest options are:

1. **Open an issue** describing the tool/resource and where it belongs in the table; or
2. **Submit a pull request** editing `README.md`.

For a new entry, please provide:

- **Type** — what the tool/resource does;
- **Name** — the project or resource name;
- **Reference** — the primary paper or documentation citation, when available;
- **Link** — the canonical project, repository, documentation, or data page;
- a brief note in the pull request explaining why it is relevant to quantitative face-perception research.

For corrections or updates, please identify the existing entry and provide the replacement information.

## Organization

Please place new entries under the closest existing category. If no category fits, propose a short descriptive category rather than creating several narrowly specific headings.

## Maintenance

Links, release status, and software availability change over time. Pull requests that update broken links, newly released code, renamed projects, or deprecated resources are especially welcome.
